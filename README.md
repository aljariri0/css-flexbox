# Simple Flexbox Landing Page

A minimal search-engine style landing page built with **HTML5** and **CSS Flexbox**. This project demonstrates basic CSS Flexbox layouts, including space-between navigation bars, centered content alignment, and a sticky footer pinned to the bottom of the viewport.

---

## Features

- **Sticky Footer Layout:** Uses a flex-column body (`min-height: 100vh`) and `flex: 1` on the main section to keep the footer at the bottom of the screen.
- **Flexbox Navigation & Footer:** Distributes links evenly across left and right sides using `justify-content: space-between`.
- **Centered Hero Section:** Clean input field and call-to-action buttons aligned centrally.
- **Clean Typography & Styles:** Styled links, hover state on buttons, and box-sizing resets.
